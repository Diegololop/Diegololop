## Proyectos

### Servtec

**www.servtec.cl**

Plataforma integral de gestión de órdenes y encargos para un negocio de servicio técnico y venta de equipos.

El negocio dependía de un computador específico para poder buscar el estado de una orden, lo que generaba demoras constantes. Servtec resuelve esto centralizando la información: desde cualquier lugar del mundo el equipo puede consultar y actualizar el estado de una orden en tiempo real.

Incluye panel de administración con dashboard e informes, control de inventario y seguimiento de equipos no retirados, notificaciones y atención al cliente integradas con WhatsApp, gestión de fotos de productos, autenticación y perfiles de cliente, un backend serverless con webhooks y tareas programadas (descuentos de cumpleaños, sorteos quincenales, gestión de sesiones), y un punto de venta físico independiente integrado con Transbank para pagos con tarjeta en Chile.

**Stack:** React, Vite, TypeScript, Supabase, funciones serverless en Vercel.

**Rol:** desarrollo full stack del sistema completo (aplicación principal, panel admin, backend y punto de venta).

### SmartCall

**www.smartcallvercel.cl**

Sistema de gestión para SmartCall, un taller de reparación de celulares y computadores en San Antonio, Chile. Funciona como un ERP/CRM ligero para administrar todo el ciclo de un taller técnico.

Cubre autenticación y roles de staff, creación y seguimiento de órdenes de servicio con impresión de guías de trabajo, un flujo de presupuestos donde el cliente puede aprobar o rechazar una cotización a distancia mediante un enlace, dashboards separados para el equipo interno y para clientes, control de inventario y pedidos a proveedores, y reportes con registro de actividad para auditoría.

**Stack:** React, TypeScript, Vite, Supabase (autenticación, base de datos y Edge Functions), desplegado en Vercel.

**Rol:** desarrollo full stack del sistema completo.

### Mirador Marchigüe

**www.miradormarchigue.cl**

Sitio web comercial para un proyecto inmobiliario de parcelas ubicado en la Ruta 90, cerca de Pichilemu, Chile.

Es un sitio estático con un mapa satelital interactivo que muestra los 31 lotes disponibles, plano del proyecto, ubicación, galería de fotos y tour virtual. Incluye además una herramienta interna, no indexada por buscadores, para calibrar visualmente la posición de los deslindes y los lotes sobre la imagen satelital, junto con una capa personalizada para controlar el consumo de tiles de mapas y mantener acotado el gasto asociado.

**Stack:** Vite, Tailwind CSS, Leaflet/Mapbox.

**Rol:** desarrollo completo del sitio y de las herramientas internas de calibración del mapa.

### Vental

**vental.cl**

Sistema de punto de venta (POS) de escritorio pensado para minimarkets y almacenes de barrio, capaz de operar sin conexión a internet.

Permite registrar ventas de forma rápida, manejar productos por unidad o por peso, controlar stock en tiempo real, imprimir boletas en impresora térmica y generar reportes de ventas. Está diseñado para negocios con una o varias cajas operando bajo un mismo control central.

Este proyecto lo diseñé y desarrollé por iniciativa propia para adentrarme en el desarrollo de aplicaciones de escritorio.

**Stack:** aplicación de escritorio para Windows, desarrollada en IntelliJ.

**Rol:** diseño y desarrollo completo, de forma independiente.

### Pauli Pez

**www.paulipez.cl**

Sitio portafolio de Paulina Sepúlveda Pérez, artista chilena dedicada al arte textil y a la pintura y el dibujo.

El sitio reúne su obra, su declaración de artista y los talleres que dicta, con una galería de más de 140 piezas filtrable por categoría, presentada en formato masonry con carga progresiva y orden aleatorio en cada visita. Es un sitio cien por ciento estático, sin backend ni base de datos, con una estética cálida y editorial acorde al trabajo de la artista.

**Stack:** HTML, CSS y JavaScript vanilla, sin frameworks ni backend.

**Rol:** desarrollo completo del sitio.
